## 项目简介

PVMouse 3.0（Panoramic Virtual Mouse V3.0）提出以虚拟小鼠为起点，构建生物世界模型的最小可行产品（MVP）。其核心是用统一的生物状态空间连接分子知识、细胞状态、器官空间结构和器官间相互作用，将当前状态估计、干预响应预测和实验反馈纳入同一研究框架。

初始范围限定为 **C57BL/6J 小鼠的脑、心脏、肝脏、骨骼肌和脾脏**，遵循“**先重建正常状态，再模拟偏离**”的开发顺序。每次推断仍应从具体动物的当前遗传条件、处理历史和可用观测出发。

> **当前状态：** 本仓库发布白皮书和配套说明文件。根据白皮书，项目已构建部分算法组件，正在清洗已收集数据；完整系统仍待完成与验证。本仓库不包含可运行模型、训练权重或研究数据集。文中预测能力与应用场景属于研究目标，不代表已经验证的性能。

## 核心科学问题

相对于简单基线，增加细胞、空间和多器官信息，是否能够提高特定干预条件下分子响应与功能结果的预测能力？

白皮书提出四类目标能力：当前生物状态估计、给定时间范围内的状态变化预测、不同干预条件下的响应比较，以及不确定性估计与后续实验选择。因果效应与个体反事实的解释需要相应实验设计和可识别性假设支持。

## 四层架构

| 层级 | 主要作用 |
| --- | --- |
| 分子层 | 整合基因调控、蛋白相互作用、配体受体、通路等有来源记录的先验知识。 |
| 细胞层 | 结合小鼠组织、年龄与生物学背景建立细胞状态参考。 |
| 空间器官层 | 从细胞状态、组成与空间组织形成区域和器官状态，并连接观测读出。 |
| 多器官层 | 联合描述器官关系、遗传扰动响应与时间变化，预测表达及相关表型。 |

生理、生化与病理测量共同约束模型；独立实验结果用于检验预测并指导模型修订。

## 初始任务与验证

- 以单基因敲除和适当匹配的对照作为首批建模与测试任务。
- 保留同一动物不同组织及功能测量之间的配对关系。
- 分别评估“利用同一动物已有测量估计缺失观测”和“仅利用查询时可获得的信息预测干预后果”。
- 以动物为基本独立单位划分数据；同一动物的组织和重复观测进入同一集合。
- 与简单基线比较，并通过消融、独立数据和不确定性校准检验新增信息与复杂模块的价值。
- 区分跨年龄人群参考与个体纵向轨迹；横断面年龄数据本身不能直接证明个体动态。

| 数据集合 | 报告的组织样本数 |
| --- | ---: |
| C57BL/6J 参考 bulk RNA-seq，覆盖 1–116 周龄 | 4,741 |

这些数值是**组织样本数，不是动物数**；775 个脑样本已包含在前述集合中。数据集未随本仓库公开分发。

## 开发顺序与后续方向

共享数据与参考组件 → 脑空间原型 → 其余四个器官模块 → 正常五器官联合状态 → 遗传扰动与时间建模。

药物适应证探索、组合与给药方案比较、多组织风险识别、靶点优选及监测指标筛选属于白皮书讨论的潜在研究应用。药物、饮食和环境干预，以及新增器官、遗传背景和观测模态，均依赖对应数据、任务适配与独立验证。向人类系统拓展是长期研究方向。
